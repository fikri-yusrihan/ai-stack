# Onboard the Workflow

Use this public entry point for a first-time setup or for onboarding a new machine into an existing docs workspace. Ask for the docs root only if you cannot infer it.

Follow the [workspace setup skill](../ai-workflow/SKILL.md) from the public bundle. If this entry point was installed separately, invoke the installed `ai-workflow` setup skill or locate the public bundle, then follow its setup and upgrade instructions. Confirm which skills and persona prompts are available in the user's harness.

Use [Start Project](../ai-workflow/skills/start-project/SKILL.md) when the user asks to create a project inside the installed docs workspace. Use [Resume Project](../ai-workflow/skills/resume-project/SKILL.md) to continue an existing project.
